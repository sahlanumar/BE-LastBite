# LastBite Backend

Backend service that powers the LastBite ecosystem, including APIs for customer, partner, and admin platforms.

## 🚀 Tech Stack
- Java Spring Boot

## 🔧 Installation

```bash
git clone git@git.enigmacamp.com:enigma-camp/gosling-class/batch-7/tim-challenge/new-group/team-3/final-project/lastbite-backend.git
cd lastbite-backend
./mvnw spring-boot:run
```
